# Dashboard CSS Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Consolidate and complete the MYBOT dashboard UI so every existing workspace has a coherent, accessible, responsive operations interface.

**Architecture:** Keep the dashboard DOM and JavaScript contracts intact. Replace the competing sections in the single stylesheet with one ordered CSS system: tokens and reset, shell, shared components, Overview, then responsive/accessibility rules. Browser screenshots validate the rendered result rather than relying on static selectors alone.

**Tech Stack:** Plain HTML/CSS, vanilla browser JavaScript, Font Awesome, Space Grotesk, JetBrains Mono, Node test runner, Puppeteer.

## Global Constraints

- Preserve current dashboard routes, IDs, class names, API contracts, and JavaScript behavior.
- Add no runtime dependency or frontend framework.
- Use existing Space Grotesk and JetBrains Mono assets.
- Keep UI surface radii at 8px or less.
- Support desktop at 1280px and mobile at 390px without page-level horizontal overflow.
- Honor `prefers-reduced-motion`.
